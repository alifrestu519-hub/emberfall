EMBERFALL — The Last Lantern: a top-down arena-survival game. Guard the last lantern through 5 waves and a boss, collect ember shards, level up with boons, and survive until dawn breaks.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.
